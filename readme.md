# Yo! 👋 I'm Aditya Jha

I port ColorOS and OxygenOS 16 onto Snapdragon 888 devices and write kernels for them. Sometimes websites.

### Stuff I'm working on

- **[Exhale](https://github.com/ozyern/Exhale)** - open source android music player, kotlin
- **[BrinaOS](https://github.com/ozyern/BrinaOS)** - my ColorOS 16 porting project for SM8350
- **[Feather Kernel](https://github.com/ozyern/Feather-Kernel-SM8350)** - OnePlus 9/9 Pro, 5.4.302, SukiSU Ultra + SusFS
- **[sabrina.ozyern.me](https://github.com/ozyern/sabrinacarpenter)** - fan site, my favourite thing i've made
- **[HyperOS_lemonadep](https://github.com/ozyern/HyperOS_lemonadep)** - hyperos porter for the 9 Pro
- spoofer modules for [OnePlus 15](https://github.com/ozyern/oneplus15-spoofer), [Find X9 Ultra](https://github.com/ozyern/FindX9Ultra-spoofer), [S26 Ultra](https://github.com/ozyern/s26-ultra-spoofer)

I also run [ReVork](https://t.me/ozyern), a telegram community for rom devs. Around 370 people now.

Most of what I make ends up named after a Sabrina Carpenter song. Feather, Espresso, Singular, Tornado. 🎵

Currently learning kotlin properly and trying to understand kernel internals past the point of copying patches.

### My setup

- **💻** ROG Strix SCAR 16 (2025), everything gets built here
- **📱** OnePlus 13 daily, stock OxygenOS 16
- **📱** OnePlus 9 Pro (`lemonadep`) for testing, currently unbootable
- **🐧** Ubuntu + bash
