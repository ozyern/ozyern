### 🚀 What I'm building

- **[Exhale](https://github.com/ozyern/Exhale)** 🎵 — A breath of fresh air for your music. Open source Android player with a fluid Liquid Glass UI and a library scanner that's actually fast. `Kotlin`
- **[BrinaOS](https://github.com/ozyern/BrinaOS)** 🧪 — My ColorOS / OxygenOS 16 porting project for SM8350. Partition work, smali patching, OTA generation, feature unlocking. `Shell`
- **[Feather Kernel](https://github.com/ozyern/Feather-Kernel-SM8350)** ⚡ — Custom kernel for the OnePlus 9 / 9 Pro. Linux 5.4.302 with SukiSU Ultra + SusFS 2.2.0. `C`
- **[sabrina.ozyern.me](https://github.com/ozyern/sabrinacarpenter)** 💗 — My love for Sabrina in website form. Era filtered discography, Dynamic Island nav, gallery, birthday campaign. `HTML/CSS/JS`
- **[HyperOS_lemonadep](https://github.com/ozyern/HyperOS_lemonadep)** 🤖 — Automatic HyperOS porter for the OnePlus 9 Pro. `Python`
- 🎭 Plus a few KernelSU/Magisk spoofers — **[OnePlus 15](https://github.com/ozyern/oneplus15-spoofer)**, **[Find X9 Ultra](https://github.com/ozyern/FindX9Ultra-spoofer)**, **[S26 Ultra](https://github.com/ozyern/s26-ultra-spoofer)** — for when a device needs to believe it's something else.
